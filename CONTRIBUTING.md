# Contributing

ForgeFleet is developed by multiple parallel AI coding agents under coordinator supervision.

1. Branch `feat/<issue>-<short-name>` or `fix/<issue>-<short-name>` off `develop` after dependencies are satisfied.
2. Read `AGENTS.md`, read the spec files the issue names, and lock the intended file ownership in the issue or coordinator task ledger.
3. Update implementation, tests, documentation and contracts together when behavior changes.
4. Submit PR to `develop`. Do not merge it yourself. Check required CI, obtain an independent review, and wait for coordinator approval.
5. Record evidence clearly: actual tested behavior versus mocked/inferred behavior.

This specs-only scaffold is a **planning baseline**. Source code, packages, CI, and deployment scripts still need implementation. Never represent a proposed path as an existing executable.
