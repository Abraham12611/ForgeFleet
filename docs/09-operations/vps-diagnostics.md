# VPS diagnostic evidence template (non-sensitive)

> This is a template; no commands were run on the user's Vultr host during spec preparation.

## Required fields

- OS and architecture:
- Available RAM/CPU/disk (counts/usage only):
- Orca user service status and uptime:
- Service ExecStart path (redact private args):
- Selected `ORCA_CLI_COMMAND` / `orca-ide` binary and version:
- Version-matched `skills get orchestration` summary:
- Agent providers discovered (Muse, Devin):
- Supported launch/status/message/cancel paths:
- Number of known worktrees/sessions (no secrets):
- Paperclip release/adapter API version:
- GitHub test repository/protections:
- Ports bound publicly (report only non-secret):
- Tailscale connectivity:
- Open blockers and recommended safe next steps:

## Do not include

SSH private keys, PAT, `.env`, provider sessions, cookies, access tokens, personal repo contents, raw agent transcripts, real uploaded project context or full unredacted process environment.
